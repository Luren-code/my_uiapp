## 准备工作

在开始之前,请确保您已准备:

- ✅ 一台电脑(Windows、macOS或Linux)
- ✅ 稳定的网络连接
- ✅ 已安装Node.js (v14.x或更高版本)
- ✅ 微信账号(用于登录开发者工具)
- ✅ GitHub账号(用于克隆项目)

## 下载和安装微信开发者工具

### 步骤1: 访问官方下载页面

打开浏览器,访问微信开发者工具下载页面:

```
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

### 步骤2: 选择适合您系统的版本

根据您的操作系统选择对应的版本:

- **Windows 64位**: 下载 `Windows x64` 版本
- **Windows 32位**: 下载 `Windows ia32` 版本
- **macOS**: 下载 `macOS` 版本(支持Intel和Apple Silicon)
- **Linux**: 下载对应的Linux版本

### 步骤3: 安装开发者工具

#### Windows系统:
1. 双击下载的 `.exe` 安装包
2. 按照安装向导提示完成安装
3. 建议保持默认安装路径
4. 安装完成后,桌面会出现"微信开发者工具"图标

#### macOS系统:
1. 双击下载的 `.dmg` 文件
2. 将"微信开发者工具"图标拖拽到"Applications"文件夹
3. 首次打开时,如果系统提示"无法打开",请前往"系统偏好设置" → "安全性与隐私" → 点击"仍要打开"
4. 从"启动台"或"应用程序"文件夹打开工具

#### Linux系统:
1. 解压下载的压缩包
2. 进入解压后的目录
3. 运行 `./wechatdevtools` 启动工具

### 步骤4: 首次启动和登录

1. 启动微信开发者工具
2. 使用微信扫码登录(打开手机微信,扫描屏幕上的二维码)
3. 在手机上确认登录
4. 登录成功后,会显示项目管理界面

## 获取小程序AppID

### 方式一: 使用项目提供的测试AppID (推荐新手)

本项目已包含一个测试AppID: `wx2beddb4ba7cd06d0`

您可以直接使用这个AppID进行开发和调试,无需额外注册。

### 方式二: 注册自己的小程序账号

如果您想使用自己的AppID,请按以下步骤操作:

#### 1. 访问微信公众平台
```
https://mp.weixin.qq.com/
```

#### 2. 注册小程序账号
- 点击右上角"立即注册"
- 选择"小程序"类型
- 填写邮箱、密码等信息
- 验证邮箱
- 填写主体信息(个人或企业)
- 完成注册

#### 3. 获取AppID
- 登录微信公众平台
- 进入"开发" → "开发管理" → "开发设置"
- 在页面顶部找到"开发者ID"
- 复制"AppID(小程序ID)"

#### 4. 设置服务器域名(如果需要)
- 在"开发管理" → "开发设置" → "服务器域名"中
- 配置request合法域名、uploadFile合法域名等
- 本项目暂时不需要配置(使用本地数据)

## 克隆项目到本地

### 步骤1: 打开终端/命令提示符

**Windows系统:**
- 按 `Win + R`,输入 `cmd`,按回车
- 或搜索"命令提示符"并打开

**macOS系统:**
- 按 `Command + 空格`,搜索"终端"并打开
- 或在"应用程序" → "实用工具"中找到"终端"

**Linux系统:**
- 按 `Ctrl + Alt + T` 打开终端

### 步骤2: 选择项目存放位置

建议在桌面或文档目录创建项目文件夹:

```bash
# Windows示例
cd C:\Users\YourUsername\Desktop

# macOS/Linux示例
cd ~/Desktop
```

### 步骤3: 克隆项目

使用以下命令克隆项目(请替换为实际的GitHub仓库地址):

```bash
# 通过HTTPS克隆
git clone https://github.com/your-username/my-eoi-app.git

# 或通过SSH克隆(如果已配置SSH密钥)
git clone git@github.com:your-username/my-eoi-app.git
```

### 步骤4: 进入项目目录

```bash
cd my-eoi-app
```

## 安装项目依赖

### 步骤1: 检查Node.js版本

确保Node.js已正确安装:

```bash
node -v
# 应显示类似: v14.17.0 或更高版本

npm -v
# 应显示类似: 6.14.13 或更高版本
```

如果显示"命令未找到",请先安装Node.js:
- 访问 https://nodejs.org/
- 下载并安装LTS(长期支持)版本

### 步骤2: 安装项目依赖

在项目根目录执行:

```bash
npm install
```

**可能遇到的情况:**

1. **安装速度慢或超时**
   
   使用淘宝镜像加速:
   ```bash
   npm install --registry=https://registry.npmmirror.com
   ```

2. **权限错误(macOS/Linux)**
   
   不要使用sudo,如果遇到权限问题:
   ```bash
   sudo chown -R $(whoami) ~/.npm
   npm install
   ```

3. **网络错误**
   
   检查网络连接,或使用VPN后重试

### 步骤3: 等待安装完成

安装过程可能需要3-10分钟,取决于网络速度。

安装完成后,您会看到类似以下输出:
```
added XXX packages in XXs
```

## 导入项目到微信开发者工具

### 步骤1: 启动微信开发者工具

- 双击桌面上的"微信开发者工具"图标
- 使用微信扫码登录(如果未登录)

### 步骤2: 点击"导入项目"

在微信开发者工具的主界面:

1. 点击左侧的 **"+"** 号(或点击"导入项目"按钮)
2. 进入项目导入界面

### 步骤3: 填写项目信息

在导入界面,需要填写以下信息:

#### 1. 项目目录
- 点击"目录"右侧的**选择**按钮
- 浏览并选择刚才克隆的项目文件夹: `my-eoi-app`
- **重要**: 选择项目根目录(包含 `pages.json` 文件的目录)
- 选择正确后,路径应类似于: `C:\Users\YourName\Desktop\my-eoi-app` 或 `/Users/yourname/Desktop/my-eoi-app`

#### 2. AppID
有三种选择:

**选项A: 使用项目测试AppID(推荐)**
- 选择"小程序"
- 输入AppID: `wx2beddb4ba7cd06d0`

**选项B: 使用自己的AppID**
- 选择"小程序"  
- 输入您自己注册的AppID

**选项C: 使用测试号**
- 点击"使用测试号"
- 系统会自动分配一个临时AppID
- 注意: 测试号功能有限制,不能发布

#### 3. 项目名称
- 可以保持默认: `my-eoi-app`
- 或修改为您喜欢的名称,如: `EOI职业查询小程序`

#### 4. 开发模式
- 选择: **小程序** (默认)

### 步骤4: 点击"导入"按钮

- 检查填写的信息是否正确
- 点击右下角的**"导入"**按钮
- 等待几秒钟,工具会自动加载项目

### 步骤5: 等待项目加载

导入成功后,您会看到:
- 左侧是项目文件树
- 中间是模拟器(显示小程序界面)
- 右侧是调试工具

## 运行和调试

### 界面布局说明

微信开发者工具的界面分为几个主要区域:

```
┌──────────────────────────────────────────────────────────┐
│  菜单栏: 项目 | 工具 | 调试 | 设置                           │
├──────────────────────────────────────────────────────────┤
│  工具栏: 编译 | 预览 | 真机调试 | 清缓存 | 上传 | 详情       │
├──────────┬─────────────────────┬──────────────────────────┤
│          │                     │                          │
│  文件树  │     模拟器界面      │      调试工具窗口        │
│          │                     │                          │
│  pages/  │  ┌───────────────┐  │  Console | Sources |... │
│  comp... │  │  小程序预览   │  │                          │
│  utils/  │  │               │  │  显示日志和错误信息      │
│  ...     │  │     [界面]    │  │                          │
│          │  └───────────────┘  │                          │
└──────────┴─────────────────────┴──────────────────────────┘
```

### 首次编译

1. **自动编译**: 导入后,项目会自动编译
2. **手动编译**: 点击工具栏的**"编译"**按钮
3. **查看结果**: 编译完成后,模拟器会显示小程序首页

### 模拟器使用

#### 基本操作:
- **鼠标点击**: 模拟点击操作
- **鼠标滚轮**: 模拟上下滚动
- **切换设备**: 点击模拟器顶部的设备型号,可切换不同手机型号

#### 模拟器工具栏:
- **旋转**: 切换横屏/竖屏
- **缩放**: 调整模拟器显示大小
- **返回/主页**: 模拟物理按键
- **网络**: 模拟不同网络环境(WiFi、4G、弱网等)

### 调试工具

#### Console(控制台):
- 显示 `console.log()` 输出
- 显示错误和警告信息
- 可以直接输入JavaScript代码执行

#### Sources(源代码):
- 查看编译后的代码
- 设置断点调试
- 单步执行代码

#### Network(网络):
- 查看网络请求
- 检查API调用情况
- 查看请求和响应数据

#### Storage(存储):
- 查看本地存储数据
- 查看缓存内容
- 清除存储数据

### 真机预览

#### 步骤1: 点击"预览"按钮
- 在工具栏点击**"预览"**按钮
- 会生成一个二维码

#### 步骤2: 扫码查看
- 打开手机微信
- 扫描二维码
- 在真机上查看和测试小程序

#### 注意事项:
- 手机微信需要是最新版本
- 手机和电脑需要在同一网络环境(或使用移动网络)
- 预览码有效期30分钟

### 真机调试

#### 步骤1: 点击"真机调试"按钮
- 在工具栏点击**"真机调试"**按钮
- 生成调试二维码

#### 步骤2: 扫码连接
- 用手机微信扫描二维码
- 手机上会打开小程序
- 开发者工具的调试窗口会显示手机的调试信息

#### 步骤3: 调试操作
- 在手机上操作小程序
- 在电脑上查看日志和调试信息
- 可以在电脑上直接调试手机上运行的代码

## 常见问题解决

### 问题1: 导入项目时提示"不是有效的小程序项目"

**原因**: 选择的目录不正确

**解决方案**:
1. 确保选择的是项目根目录(包含 `pages.json` 文件)
2. 检查是否已运行 `npm install` 安装依赖
3. 尝试重新克隆项目

### 问题2: 模拟器显示空白或报错

**可能原因和解决方案**:

#### 原因1: 依赖未安装
```bash
# 重新安装依赖
npm install
```

#### 原因2: 编译错误
- 查看Console控制台的错误信息
- 点击"详情" → "本地设置" → 勾选"不校验合法域名、web-view..."
- 点击工具栏"清缓存" → "清除数据缓存" → 重新编译

#### 原因3: AppID问题
- 使用项目提供的测试AppID: `wx2beddb4ba7cd06d0`
- 或点击"详情" → 修改AppID

### 问题3: 提示"未找到入口app.json文件"

**解决方案**:
1. 检查项目目录是否完整
2. 确认 `pages.json` 文件存在
3. 尝试重新导入项目:
   - 关闭当前项目
   - 点击"+" → 重新导入

### 问题4: 网络请求失败

**解决方案**:
1. 点击"详情"标签页
2. 在"本地设置"中勾选:
   - ✅ 不校验合法域名、web-view(业务域名)、TLS版本以及HTTPS证书
3. 重新编译项目

### 问题5: 代码修改后没有生效

**解决方案**:
1. **清除缓存**: 工具栏 → "清缓存" → "清除数据缓存"
2. **重新编译**: 点击"编译"按钮
3. **重启工具**: 关闭并重新打开微信开发者工具
4. **检查保存**: 确保代码文件已保存(Ctrl+S / Command+S)

### 问题6: 无法扫码预览

**可能原因和解决方案**:

#### 原因1: 微信版本过低
- 更新手机微信到最新版本

#### 原因2: 网络问题
- 确保手机和电脑在同一网络
- 或手机使用移动数据网络

#### 原因3: AppID权限问题
- 使用项目提供的测试AppID
- 或检查自己的AppID是否正确配置

### 问题7: 开发者工具卡顿或崩溃

**解决方案**:
1. **关闭不必要的标签页**: 减少打开的文件数量
2. **清理缓存**: 工具 → 清除工具授权数据
3. **重启工具**: 完全退出后重新启动
4. **更新工具**: 帮助 → 检查更新
5. **降低模拟器质量**: 设置 → 外观设置 → 降低界面渲染质量

### 问题8: uni_modules组件不显示

**解决方案**:
1. 确认 `uni_modules` 目录完整存在
2. 检查项目结构是否正确
3. 重新安装依赖:
   ```bash
   rm -rf node_modules
   npm install
   ```
4. 清除缓存并重新编译

### 问题9: 提示"开发者工具版本过低"

**解决方案**:
1. 点击菜单栏"帮助" → "检查更新"
2. 下载并安装最新版本
3. 或访问官网下载最新版: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 问题10: 登录二维码不显示或扫码失败

**解决方案**:
1. **检查网络连接**: 确保电脑可以正常上网
2. **刷新二维码**: 点击二维码下方的"刷新"按钮
3. **使用手机号登录**: 如果有绑定手机号,可以点击"使用手机号登录"
4. **重启工具**: 完全退出后重新启动
5. **检查防火墙**: 确保防火墙没有阻止微信开发者工具的网络连接

## 开发技巧

### 快捷键

**Windows/Linux:**
- `Ctrl + S`: 保存文件
- `Ctrl + B`: 编译项目
- `Ctrl + F`: 查找
- `Ctrl + H`: 替换
- `Ctrl + /`: 注释/取消注释
- `Ctrl + D`: 删除当前行
- `Ctrl + Z`: 撤销
- `Ctrl + Shift + Z`: 重做

**macOS:**
- `Command + S`: 保存文件
- `Command + B`: 编译项目
- `Command + F`: 查找
- `Command + Option + F`: 替换
- `Command + /`: 注释/取消注释

- `Command + Shift + Z`: 重做

设置自动保存功能:
1. 点击"设置" → "编辑设置"
2. 勾选"文件保存时自动编译小程序"

### 代码格式化

格式化代码:
- Windows/Linux: `Shift + Alt + F`
- macOS: `Shift + Option + F`

### 多设备测试

测试不同设备适配:
1. 点击模拟器顶部的设备名称
2. 选择不同的手机型号(iPhone X、iPhone 12、小米、华为等)

## 项目配置优化

### 推荐的本地设置

在"详情" → "本地设置"中,建议勾选:

- ✅ 不校验合法域名、web-view(业务域名)、TLS版本以及HTTPS证书
- ✅ 启用自定义处理命令
- ✅ 启用自动编译
- ⬜ 不启用ES6转ES5(本项目已配置)
- ⬜ 不启用增强编译(可能导致兼容性问题)

### AppID配置(如需修改)

如果需要更改AppID:

1. 点击工具栏的"详情"按钮
2. 在"基本信息"标签页找到"AppID"
3. 点击"修改"按钮
4. 输入新的AppID或选择测试号
5. 点击"确定"并重新编译
